# Python - Core Data Structures

This directory contains Python exercises focused on core data structures.

## Task 0: Print a List of Integers

File: `print_list_integer.py`

Defines a function that prints all integers in a list, one per line, using the required `:d` formatting.

## Task 1: Safe Access to a List Element

File: `element_at.py`

Defines a function that retrieves an element from a list using its index.
Returns `None` if the index is negative or out of range.

## Task 2: Replace an Element in a List

File: `replace_in_list.py`

Defines a function that replaces an element at a specified index.
Returns the original list unchanged if the index is negative or out of range.

## Task 3: Print a Matrix of Integers

File: `print_matrix_integer.py`

Defines a function that prints a matrix of integers.
Each row appears on a separate line, with integers separated by a single space.

## Task 4: Tuple Addition

File: `add_tuple.py`

Defines a function that adds the first two elements of two tuples.
Missing values are treated as zero, and extra values are ignored.
Returns a new tuple containing exactly two integers.

## Task 5: Common Elements in Two Sets

File: `common_elements.py`

Defines a function that returns a new set containing elements
present in both input sets using the intersection method.

## Task 6: Update or Add a Key/Value in a Dictionary

File: `update_dictionary.py`

Defines a function that updates an existing dictionary key or adds
a new key/value pair if the key does not exist.
Returns the updated dictionary.

## Task 7: Best Score

File: `best_score.py`

Defines a function that returns the dictionary key associated
with the highest integer value.
Returns `None` if the dictionary is empty or `None`.
