# Python - Control Flow

## Description

This project is part of the Holberton School Core Engineering
curriculum. It focuses on controlling program execution using
conditional statements, comparison operators, Boolean logic,
and loops in Python.

## Learning Objectives

- Understand and use if, elif, and else statements.
- Apply comparison and logical operators.
- Use while loops and for loops with range().
- Understand loop boundaries and iteration.
- Generate formatted output using loops.
- Combine conditions and loops to solve programming problems.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.x
- PEP8 coding style
- Executable Python scripts
- No external libraries
- No function definitions
- No import statements

## Tasks

### 0. Positive anything is better than negative nothing

File: `positive_or_negative.py`

Generates a random integer between -10 and 10 and prints whether
the number is positive, negative, or zero.
